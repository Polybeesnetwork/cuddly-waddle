# Roadmap

1. **Prototype (done):** premium dashboard, public RPC chain/balance reads, local watchlist, direct transfer observations and evidence links; synthetic unit tests.
2. **Reliability:** independent RPC quorum, bounded backfill, canonicality/reorg tracking, persisted event model, polling-gap diagnostics, alert delivery, accessibility and browser test suite.
3. **Policy & campaign:** signed/versioned campaign policy, verified treasury control display, milestone evidence provenance and contributor receipt.
4. **Testnet escrow:** all-or-nothing funding deadline, unique campaign IDs, event attribution, refunds and releases; fuzz/invariant tests, independent security review. No real funds.
5. **Legal/customer validation:** Malaysian counsel, user interviews, service provider costs, pricing test and compliance assessment.
6. **Production readiness:** incident on-call runbooks, privacy review, audits, legal approvals and separate explicit authorization. Mainnet payments/fundraising stay disabled until then.
